Назначение и доступ

Atlas Local — личное приложение Георгия Семёнова. После согласия владельца оно получает доступ только на чтение к сообщениям и метаданным Gmail, событиям календаря, метаданным и выбранному содержимому Drive, Google Docs и Google Sheets. Идентификатор аккаунта используется для выбора подключённого источника.

Использование

Данные используются для поиска, сводок, ответов на вопросы, подготовки к встречам и ведения личной базы знаний. Приложение не отправляет письма и не изменяет или удаляет исходные данные Google.

Хранение и передача

Учётные данные подключения хранятся отдельно от базы знаний в системном хранилище компьютера владельца. Прочитанные сведения, сводки и история работы могут сохраняться в личном хранилище и его резервных копиях.

Для подготовки ответов релевантные фрагменты могут передаваться через шлюз ApiClo выбранному поставщику языковой модели. При работе через Telegram вопросы и ответы проходят через Telegram. Эти сервисы обрабатывают переданные данные согласно своим условиям; приложение не гарантирует исключительно локальную обработку или отсутствие хранения у поставщиков.

Данные Google не публикуются на этом сайте, не продаются и не используются приложением для рекламы. Приложение не использует их для обучения обобщённых моделей искусственного интеллекта. Передача поставщикам допускается только для выполнения пользовательских функций и в пределах Google API Services User Data Policy, включая требования Limited Use.

Срок хранения и отзыв доступа

Локальные материалы сохраняются, пока нужны владельцу, либо до их удаления владельцем. Отозвать доступ можно в разделе подключений сторонних приложений Google-аккаунта. Отзыв прекращает дальнейшее получение данных, но сам по себе не удаляет ранее сохранённые копии, журналы или резервные копии; их следует удалить отдельно. Копии у внешних поставщиков регулируются их правилами хранения.

Этот сайт

Сайт содержит только справочные страницы, без формы входа и подключения к Google API. Мы не добавляем рекламные трекеры или аналитику. Хостинг GitHub Pages может обрабатывать стандартные сведения о посещении, включая IP-адрес, согласно политике GitHub.
